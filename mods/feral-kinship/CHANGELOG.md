# Feral Kinship 0.5.6

another page from the stolen computer. here is what changed in this version, with the test limits left attached.

Since public release 0.5.5

- Added admin commands to set or clear an online player's kinship: /kinship set <player> <kinship> and /kinship clear <player>.
