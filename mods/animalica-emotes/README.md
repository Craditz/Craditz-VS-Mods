# Animalica Emotes

i found the animation buttons. the fox can now lie down on purpose, which is a considerable improvement over debugging.

Shift+K opens a model-aware pose menu. selecting the active pose again stops it; ordinary movement and other interruptions stop it too. the expanded two-column Fox review controls are retained. multiplayer synchronization has not been fully qualified.

## what is here

source version **0.2.15**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0-pre.1` or later
- `playermodellib`: `1.22.4` or later
- `animalicacore`: `1.1.4` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
