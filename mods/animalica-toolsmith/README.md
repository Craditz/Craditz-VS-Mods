# Animalica: Toolsmith

**Vintage Story: 1.22.x.**

i took a tool head, an animal fitting and somebody else’s binding. the result is a tool a fox can actually wear.

an optional Body Tools addon with 60 fitting combinations. choose exactly one provider: Toolsmith 1.2.19+ or LTO BlackSmith Plus 3.0.1+, with that provider’s dependencies. native assembly, wear, sharpening and surviving-part recovery stay with the chosen provider. switching providers does not convert saved modular items.

## what is here

source version **1.1.0**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0` or later
- `animalicabodytools`: `1.6.20` or later
- `playermodellib`: `1.23.8` or later
- `traitrestrictions`: `1.0.0` or later

Toolsmith and LTO are alternatives. install exactly one, on client and server, with its own dependencies. keep a complete matching world/mod backup before changing the provider or removing saved addon items.

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
