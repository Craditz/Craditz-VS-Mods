# Animalica: Toolsmith 1.1.0

another page from the stolen computer. here is what changed in this version, with the test limits left attached.

For Vintage Story 1.22.X.

- Supports either Toolsmith 1.2.19+ or LTO BlackSmith Plus 3.0.1+, with the chosen
  provider's dependencies. Install exactly one provider on client and server.
- LTO integration uses its native hand/workbench assembly, component stats,
  head quality and upgrades, sharpening, wear and surviving-part recovery.
- All 60 animal fittings use the selected provider's material profiles and
  recipes. LTO's first brace tier uses plant fiber in place of rawhide strips.
- Flint axe and hoe heads under LTO produce the existing flint Rending and
  Cultivating Claws. Unsupported heads leave both components untouched.
- Supported unfinished LTO bundles with an incorrect ordinary-tool target are
  corrected when finished, retaining their component data.

Switching providers does not convert existing saved modular items. Keep the
same provider for an existing world, or use a matching world/mod backup.

Stable finalization preserves every tested runtime DLL and asset from the
accepted 1.1.0-pre.2 candidate. Exact testing used Vintage Story 1.22.7.
