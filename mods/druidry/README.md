# Druidry

one fox was apparently not enough. i borrowed the ritual altar and acquired options.

Shift+R opens the Circle of Forms. crafted spirit tokens unlock thirteen spirit families through a Ritual Altar, with server-validated changes and restoration of the player’s true form. Animalica supplies the bodies. Companions is not a dependency.

## what is here

source version **0.1.1**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
