# Bone Carving

**Vintage Story: 1.22.x.**

the fox can still make a bone handle. the patch-number label was the only carving in this update.

Hold one bone in the offhand and a vanilla knife in the main hand, then hold right-click for two seconds to carve an inert Bone Handle. Both client and server load this small proof of concept.

Source version **0.1.1**. The exact retained runtime passed the 1.22.7 Docker load/save/reload smoke. Feature-specific gameplay remains outside that smoke.
