Animalica - Compatibility Pack 2 (FotSA)

Animalica - Compatibility Pack 2 adds clothing-capable playable animal models
from the Fauna of the Stone Age collection.

The pack currently provides 151 selectable entries across these 20 optional
FotSA modules:

Supported FotSA modules:
- Pantherinae
- Sirenia
- Caninae
- Capreolinae
- Casuariidae
- Machairodontinae
- Vombatidae
- Elephantidae
- Felinae
- Spheniscidae
- Dinornithidae
- Manidae
- Rhinocerotidae
- Viverridae
- Bovinae
- Chelonioidea
- Thylacinidae
- Iniidae
- Cervinae
- Meiolaniidae

The companion mods are not hard dependencies. A model only appears when its
corresponding FotSA module is installed, so players can install only the
families they want to use.

The pack includes native animal-animation coverage, wearable clothing support,
first-person handling, and selectable Paw Carry or Mouth Carry modes. Animals
sharing the same body and animation set may be combined into a single entry
with a Species / Skin selector, reducing menu clutter without removing
appearances.

Requires Animalica Core and PlayerModelLib.

Release 0.5.3 combines restored source-folder selectors with Original / Custom
Pantherinae body texture choices and separate Lion body/mane controls.
Use Elephantidae 1.0.21, Rhinocerotidae 1.0.28, Spheniscidae 1.0.18,
Manidae 1.0.23 and Pantherinae 1.2.17 for their models; these remain optional.
Older source versions with legacy texture folders require Pack 2 0.5.2.
The Lion upgrade and restart sequence passed scoped gameplay checks.

The complete set was structurally validated, but manual in-game testing was
representative rather than exhaustive. The animals were not all tested equally,
so unusual body plans, animations, clothing, and carry positions may still
need additional review.

Special thanks to Tenth Architect, creator of Fauna of the Stone Age. Their
original animals and extensive work made this compatibility pack possible.
