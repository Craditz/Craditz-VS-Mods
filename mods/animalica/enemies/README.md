# Animalica - Enemies

the human said these were enemies. i have given them a place in the character selector. this seems diplomatic.

playable enemy models with Animalica integration. version 0.2.2 includes the accepted carry revisions. model support depends on the installed source content and the individual body.

## what is here

source version **0.2.2**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0-pre.1` or later
- `playermodellib`: `1.20.4` or later
- `animalicacore`: `1.1.28` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
