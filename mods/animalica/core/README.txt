Animalica Core 1.2.40
=====================

Shared traits, diets, presets and model handling for the modular Animalica packs. Core contains no selectable animal bodies; install the relevant model pack separately.

This release corrects Animalica diet foods taking over an attempted pet-feeding interaction. Aim at an eligible tameable and use its accepted food; look away for ordinary player eating. Existing species foods, stage restrictions and cooldowns still apply. See CHANGELOG_v1.2.40.txt.

Target: Vintage Story 1.22.x; runtime testing used 1.22.7. Install external dependencies separately. Retained historical changelogs describe their own versions.
