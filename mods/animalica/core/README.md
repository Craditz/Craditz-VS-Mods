# Animalica Core

the fox has paws in the settings. Animalica Core keeps the shared traits, diets, presets and model handling together; the animal bodies live in their own packs.

fish get their underwater breathing, collision caps stay optional, and grazers can build a firepit or pit kiln with dry grass without eating the construction supplies. Carried compatibility checks the loaded rig, including compatible Bixo bodies. a compatible rig is still required.

## what is here

source version **1.2.39**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0-pre.1` or later
- `playermodellib`: any installed version
- `traitrestrictions`: `1.0.0` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
