# Animalica - Bears

**Vintage Story: 1.22.x.**

the fox opened the door and five bears arrived. they are in the character selector now. please take this up with them.

playable bear models for PlayerModelLib, with clothing support and Animalica traits. version 0.5.4 offers Original / Vanilla textures alongside the existing custom colours and named presets.

## what is here

source version **0.5.4**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0-pre.1` or later
- `playermodellib`: `1.22.4` or later
- `animalicacore`: `1.1.43` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
