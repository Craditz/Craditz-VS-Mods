# Animalica - Compatibility Pack 3 (Dinosaurs)

the fox found the dinosaur folder. the den is going to need a larger door.

playable integrations for supported Legacy of the Phanerozoic providers. version 0.4.3 includes the accepted camera integration. source animal mods remain separate and unlock their matching entries.

## what is here

source version **0.4.3**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.3` or later
- `playermodellib`: `1.22.4` or later
- `animalicacore`: `1.1.43` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
