# Animalica - Small & Odd

**Vintage Story: 1.22.x.**

the large animals were taking up the doorway. i brought in the small and odd ones through the window.

small animals and unusual body plans for PlayerModelLib. version 0.5.5 includes the accepted salmon and grouped-selector remap work. each body keeps its own supported Animalica profile.

## what is here

source version **0.5.5**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0-pre.1` or later
- `playermodellib`: `1.22.4` or later
- `animalicacore`: `1.2.34` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
