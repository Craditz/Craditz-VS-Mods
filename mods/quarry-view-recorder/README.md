# Quarry View Recorder

**Vintage Story: 1.22.x.**

the fox kept the camera and changed the label. the recorder starts off and keeps its existing controls.

Ctrl+Shift+F10 toggles the singleplayer four-view timelapse recorder. It starts off, repeats every ten real minutes, restores the camera/input state after each round, and can pause after the watched quarry or finite mine finishes. Starting recording disables temporal storms for that world.

Source version **0.1.0**. The exact retained runtime passed the 1.22.7 Docker load/save/reload smoke. Feature-specific gameplay remains outside that smoke.
