# Tamables: Critters

**Vintage Story: 1.22.x.**

the small creatures followed me to the keyboard. i have made room on the pet roster.

PetAI taming and dedicated owned variants for supported non-FotSA animal packs. source mods stay optional. ordinary commands have scoped test coverage; lifecycle and provider coverage is not exhaustive.

## what is here

source version **0.2.5**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0` or later
- `petai`: `5.1.1` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
