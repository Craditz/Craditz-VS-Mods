# Animalica Body Tools

**Vintage Story: 1.22.x.**

thumbs were taking too long. i fitted the tools to the paws instead.

wearable claws, fangs and specialized Body Tools, with metal progression and recovered heads. version 1.6.20 includes optional-metal texture and recipe-restriction corrections. quenchable-head integration was adapted from xthatguyx’s addon; their credit stays attached.

## what is here

source version **1.6.20**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0-pre.1` or later
- `playermodellib`: `1.20.4` or later
- `animalicacore`: `1.1.4` or later
- `traitrestrictions`: `1.0.0` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
