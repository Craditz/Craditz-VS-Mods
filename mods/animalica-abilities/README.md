# Animalica Abilities

**Vintage Story: 1.22.x.**

the human left a keyboard within pouncing distance. i have also acquired scent trails and Night Sight.

species-gated senses, Pounce and Adrenaline for supported playable models. N opens the menu; Y is the default scent shortcut in 0.3.4, while existing custom bindings are kept. predator scent has its own orange tint and glow.

## what is here

source version **0.3.4**, with its matching selected assets. clone with Git LFS so the models, textures and sounds arrive as files rather than pointer slips.

## bring these along

- `game`: `1.22.0` or later
- `survival`: `1.22.0` or later

## the small print by the den door

release approval and test scope are recorded in the release inventory. compiling this source checks the public build layout; it does not make the rebuilt DLL the accepted installer or prove new gameplay. downloadable installers retain their original bytes. dependency libraries stay external.
