## what changed

the game minimum is lowered from 1.22.7 for Radio, Companions, Bone Carving and Quarry View Recorder, and from 1.22.3 for Dinosaurs. every candidate DLL, PDB and runtime asset is retained byte-for-byte. finalization changes the stable manifest version/description and release documentation only. no released DLL was rebuilt. existing provider requirements and Companions' native compatibility checks remain.

Bone Carving and Quarry View Recorder are first promoted releases. their owned source is now in this repository. Bone Carving makes an inert Bone Handle from one offhand bone and a held vanilla knife. Quarry View Recorder is an opt-in singleplayer four-view timelapse helper; it starts off, repeats at ten-minute intervals, restores camera/input state after each round and can pause after the watched quarry/finite mine completes. Starting recording disables temporal storms for that world. Their feature-specific gameplay remains outside this load smoke.

## the receipts

the owner explicitly said “good. lets push those to release now” after the reported Docker smoke. all five exact candidate runtimes loaded on client and integrated server, entered a disposable world, saved/quit, cold-loaded in a new process and saved/quit again on VS **1.22.7**. both native processes exited 0; the closed save passed SQLite quick_check. the completed fixture had zero Client/Server Error or Fatal entries. Companions' native contract qualified.

the first optional dinosaur fixture lacked the mosasaur module and produced nine unique DinoCore missing-file patch errors (18 emitted entries). adding the matching retained Ocean Tyrant provider corrected the fixture without changing a candidate. both Horrible Hands and Ocean Tyrant were present in the completed pass. Docker's original mods/data/settings and CPU limit were restored, isolation passed 15/15, and the container is stopped.

all **18** public-layout source projects compiled during release preparation. Radio retains one obsolete command-registration API warning; the others compiled without warnings. those build outputs are separate from the retained installers. complete ZIP checks cover CRCs, root manifest, safe forward-slash paths, unique normalized entries, strict version advancement and exact runtime equivalence. stable Testing and release-shelf copies match each packaged SHA-256.

## limits and backups

load/save/reload is the accepted scope. earlier 1.22 patches, radio playback, carving, recording/capture, companion jobs and exhaustive model gameplay were not newly tested. the owner accepted release on that basis; no separate owner-performed gameplay session is claimed. original limitations remain unless explicitly cleared by this smoke.

the three superseded promoted packages and sidecars are preserved in their owning archives. all other shelf bytes are unchanged. the five installed preview copies are parked intact in Testing's dated reusable folder. keep complete matching world/mod backups, especially for Companions; an older DLL alone is not a safe downgrade.
